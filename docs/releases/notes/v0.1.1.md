## 0.1.1: compatibility with newer thread responses

- Paid-thread purchases can use newer structured responses and still verify that the opening post is readable.
- Moderation recognizes supported permissions in newer responses. Operations that cannot verify their targets still stop without dispatch.
- Supported special-thread participation, including poll votes, can continue when a newer response supplies the required offer and identity.
- After creating a thread or poll, the SDK can verify exact source text with one same-session editor read when the thread identifies the post but omits its source.
