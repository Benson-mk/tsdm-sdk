# Triage labels

Each role maps to the GitHub label of the same name.

| Role / GitHub label | Apply when |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The issue is specified well enough for an agent to implement independently. |
| `ready-for-human` | Implementation requires a human. |
| `wontfix` | The maintainer has decided not to pursue the issue. |
